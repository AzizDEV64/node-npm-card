# 📦 Top 100 NPM Paketi — Türkçe Vitrin

Node.js ekosistemindeki **en popüler 100 npm paketini** Türkçe açıklamalar, interaktif kod örnekleri ve detaylı API referanslarıyla keşfedin.

> **Sıfır bağımlılık.** Saf HTML + CSS + JavaScript. Framework yok, build step yok. Sadece aç ve kullan.

---

## ✨ Özellikler

| Özellik | Açıklama |
|---------|----------|
| 🔍 **Anlık Arama** | Paket adı veya açıklamaya göre arama (`Ctrl+K`) |
| 🏷️ **18 Kategori Filtresi** | Web Framework, Veritabanı, Test, CLI, Güvenlik ve daha fazlası |
| 🖥️ **Syntax Highlighted Kod** | Her pakette 2-4 gerçek kullanım örneği |
| 📋 **Detaylı Kart İçeriği** | Sürüm, lisans, özellikler, use case, API açıklamaları, alternatifler |
| 🌓 **Açık / Koyu Tema** | Tercih `localStorage` ile kalıcı |
| 📱 **Responsive Tasarım** | Mobil, tablet ve masaüstü uyumlu |
| 📎 **Tek Tıkla Kopyalama** | `npm install` komutu ve kod örnekleri kopyalanabilir |

---

## 🚀 Hızlı Başlangıç

```bash
# Repoyu klonla
git clone https://github.com/AzizDEV64/node-npm-card.git

# Klasöre gir
cd node-npm-card

# Tarayıcıda aç (herhangi bir sunucu gerekmez)
start index.html        # Windows
open index.html         # macOS
xdg-open index.html     # Linux
```

Veya [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) VS Code eklentisi ile açabilirsiniz.

## 🤝 Katkıda Bulunma

1. Bu repoyu fork edin
2. Yeni bir branch oluşturun (`git checkout -b yeni-ozellik`)
3. Değişikliklerinizi commit edin (`git commit -m 'Yeni özellik eklendi'`)
4. Branch'e push edin (`git push origin yeni-ozellik`)
5. Pull Request açın

### Yeni Paket Ekleme

1. `packages1.js` veya `packages2.js` dosyasına paket verisi ekleyin
2. `extras.js` dosyasına detaylı bilgileri ekleyin
3. `codes1.js` veya `codes2.js` dosyasına ek kod örnekleri ekleyin
